# Support

For setup help and expected behavior, start with the [README](README.md) and the in-app Help page.

- Use [GitHub Discussions](https://github.com/shasan731/linuxpracticelab/discussions) for usage
  questions and ideas.
- Use the [bug report form](https://github.com/shasan731/linuxpracticelab/issues/new?template=bug_report.yml)
  for reproducible application problems.
- Use a [private vulnerability report](SECURITY.md#reporting-a-vulnerability) for security issues.

Include the app version, runtime version, Windows version, acceleration mode, and the full
learner-safe error message. Do not post control tokens, local databases, or private paths.
