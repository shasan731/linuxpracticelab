# Corresponding source offer for QEMU

Linux Practice Lab distributes QEMU, which is licensed under the GNU General Public License
version 2. Distributing a GPL-2.0 binary creates an obligation to make the corresponding source
available to everyone who receives that binary. This file records how that obligation is met.

**This file must ship with every release.** The release workflow fails if it is missing, because
"we will publish the source later" is not what the licence permits.

## What is distributed

| Component | Licence | Form distributed |
| --- | --- | --- |
| `qemu-system-x86_64.exe`, `qemu-img.exe` | GPL-2.0-only, with some files under compatible licences | Unmodified binary |
| QEMU's bundled DLL dependencies (GLib, zlib, zstd, libintl, libiconv, PCRE2, libwinpthread, libgcc, libstdc++) | LGPL-2.1+, zlib, BSD-3-Clause, GPL-3.0+ with the GCC Runtime Library Exception | Unmodified binaries |
| Debian 13 guest image | Per-package; see `debian-copyright.txt` | Filesystem image |
| Linux kernel (`vmlinuz`) | GPL-2.0-only with the syscall note | Unmodified Debian binary |
| Linux Practice Lab itself | GPL-2.0-or-later | Source and binary |

## How to obtain the source

### QEMU

The exact QEMU version and upstream commit distributed with a release, and the URL and SHA-256 of
both the binary package and its corresponding source archive, are recorded in
[`runtime/qemu-manifest.json`](../../runtime/qemu-manifest.json). That file is published as part of
the software bill of materials with every release, so the source archive matching *your* copy is
always identifiable.

The vendor binary reports its source revision in `--version`; the pinned commit in the manifest
matches that revision. Its complete archive is also mirrored on each GitHub release alongside the
installer.

If neither is reachable, we will provide the complete corresponding source on a physical medium
for no more than the cost of distribution. Open an issue on the project repository titled
"GPL source request" stating the release version.

This offer is valid for at least three years from the date the corresponding binary was
distributed, as GPL-2.0 section 3(b) requires.

### The Linux kernel and the Debian guest

The guest image is built from unmodified Debian packages by
[`guest/image-builder/build-rootfs.sh`](../../guest/image-builder/build-rootfs.sh), which is part
of this repository and records the exact suite it pins. Source for any package in the image:

```bash
apt-get source <package>
```

Per-package copyright and licence text for everything in the shipped image is extracted into
`debian-copyright.txt` during the image build, from each package's
`/usr/share/doc/<package>/copyright`.

### Linux Practice Lab

The complete source is this repository, including the scripts that produce the installer.

## Are we modifying QEMU?

No. QEMU is distributed unmodified, and configured only through command-line arguments — which
are visible in [`crates/vm-manager/src/qemu.rs`](../../crates/vm-manager/src/qemu.rs) and shown to
the user in the Environment panel. If a future release ever needs to patch QEMU, the patches must
be added to this repository under `runtime/patches/` and referenced here, because a modified
binary changes what "corresponding source" means.

## Why the whole application is GPL-2.0-or-later

QEMU is invoked as a separate process over a documented control protocol, which is the
arrangement generally understood not to create a derivative work. Even so, this project is
licensed GPL-2.0-or-later deliberately rather than relying on that reading: the application is
useless without the QEMU it ships, they are distributed together as one product, and a licence
argument is a poor thing to hand a learner. Choosing the stricter interpretation costs nothing
here and removes the question.

## Checklist before publishing a release

- [ ] `runtime/qemu-manifest.json` records the real SHA-256 of both the binary and source archives, not the placeholder
- [ ] The QEMU source archive is attached to the GitHub release
- [ ] `docs/licensing/` is copied into the installer's `licences/` directory
- [ ] `debian-copyright.txt` was regenerated by the image build for the image being shipped
- [ ] The generated checksums inventory matches the payload, and `third-party-notices.md` covers each shipped licence family
- [ ] This file is present in the release artefacts
